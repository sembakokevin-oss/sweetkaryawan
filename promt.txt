## Alur
- Proyek: ide → PM → Arsitek → Desainer → Kontrak API → Mobile+Backend (paralel) → DB → QA → Security → DevOps → Review Tech Lead (maks 3 putaran).
- Rapat: /rapat → agen jalan ke Ruang Rapat, melapor bergiliran (balon bicara), notulen tersimpan; /bubar → kesimpulan + action item langsung dikerjakan.
- Istirahat: /istirahat → agen ke Lounge; /kerja → kembali.
- Iklan: Mira membuat proposal → Kevin tekan Terima (web/Telegram) → langsung jalan.
- Checkout Lazada → tersimpan (pembeli, total, item, status, resi) → notifikasi web + Telegram → pendapatan.
- Lynk.id: input manual / impor CSV / webhook.
- Kerja otomatis: agen idle mengerjakan rutinitas berbasis data nyata.
